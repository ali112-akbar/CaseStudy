Q9. Plot purchasing value across years.


--- code ---
# Convert date column
df_transac['purchase_date'] = pd.to_datetime(df_transac['purchase_date'])

# Extract year
df_transac['year'] = df_transac['purchase_date'].dt.year

# Group by year
yearly = df_transac.groupby('year')['purchase_value'].sum()

# Plot
plt.figure(figsize=(10,5))
plt.plot(yearly.index, yearly.values, marker='o')
plt.title("Purchasing Value Across Years")
plt.xlabel("Year")
plt.ylabel("Total Purchase Value")
plt.grid(True)
plt.show()

Q10. Plot purchasing value across product categories.


--- code ---

plt.title("Purchasing Value Across Product Categories")

plt.ylabel("Total Purchase Value")
plt.xticks(rotation=45)
